# Concepts

Concept deliverables for a REQ that declared `process.concept: true` — the architecture /
risk buy-down / spike output the develop land gate requires before any code lands: a flat
`REQ-NNN.md` here, or a non-empty `REQ-NNN/` bundle directory when the concept phase keeps a
committed prototype. Link it from the REQ's `concept_refs:`.

Configured as `concepts_dir` in `.devsteward/config.yaml` — top-level, outside mkdocs' `docs/`.
