## Context

REQ-001 is the frozen north star: the one-paragraph statement of what this fork is for and
who it serves. Every later REQ either advances this or is out of scope. It is deliberately
hard to change — supersede it with a new REQ rather than weakening it.

This repository is a fork of [Tandoor Recipes](https://github.com/TandoorRecipes/recipes),
a self-hosted, multi-tenant recipe manager (Django + DRF backend, Vue 3 SPA). The fork
exists to run and shape Tandoor for the owner's own household, and to keep every local
change *legible and re-appliable* across upstream rebases. Local work is the point;
upstreaming is opportunistic — a feature is offered to upstream when it looks generally
useful and upstream signals it is welcome, but the fork never blocks on that. The owner is
not, and does not intend to become, a principal upstream contributor.

## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | The fork serves the owner's own deployment first | It is the only user whose needs are certain; upstream's roadmap is not ours to steer |
| 2 | Every local change is a tracked REQ, not an ad-hoc commit | The value of the fork is being able to rebase on upstream and know exactly what is ours and why |
| 3 | Upstreaming is opportunistic, never a precondition | Waiting on upstream discussion/CLA/review would stall work that already has a user |
| 4 | Upstream's invariants are not ours to break casually | Space scoping, the `guest`/`user`/`admin` groups, and the generated API client are load-bearing; diverging from them makes future rebases expensive (see CLAUDE.md § Architecture) |
| 5 | Do not diverge from upstream where a config or plugin would do | `recipes/plugins/<name>/` and settings are the cheap seams; forked core code is the expensive one |

## Requirement

This fork delivers a Tandoor deployment that fits the owner's household, with every local
divergence from upstream recorded as a REQ so it survives rebasing onto upstream `develop` —
and so any individual change can be offered upstream on its own merits when worthwhile.
